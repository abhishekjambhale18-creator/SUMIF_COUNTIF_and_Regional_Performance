### 📌 Project Overview
This lab focuses on summarizing the D-Mart retail dataset by Region using **SUMIF** and **COUNTIF** functions. Clean summary tables are created for Sales, Profit, Revenue, and Order counts.

### 📊 Regional Performance Snapshot

| Region | Sales (₹)       | Profit (₹)     | Revenue (₹)     | Orders |
|--------|-----------------|----------------|-----------------|--------|
| North  | 10,143,913      | 1,769,021      | 9,605,184       | 3,924  |
| South  | 9,851,779       | 1,714,039      | 10,025,880      | 3,853  |
| West   | 9,748,863       | 1,713,802      | 9,622,761       | 3,790  |
| East   | 9,518,322       | 1,675,278      | 9,501,536       | 3,778  |

### ✨ Key Features
- Sales by Region using `SUMIF`
- Total Profit Across Region using `SUMIF`
- Total Revenue Across Region using `SUMIF`
- Total Records According to Region using `COUNTIF`

### 🛠️ Skills Demonstrated
- SUMIF function
- COUNTIF function
- Creating executive summary tables
- Regional performance comparison
- Business insight generation

### 🔍 How to Explore
1. Open the file
2. Scroll to the right-side summary tables
3. Compare Sales, Profit, Revenue, and Order volume across regions
4. Observe that **North** leads in both Sales and Profit
