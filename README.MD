# 📊 Excel — Conditional Aggregation & Data Analysis

## 📌 Description

Performed **conditional calculation and data analysis operations** in **Microsoft Excel** using the DMart Sales Dataset. The assigned tasks involved applying **SUMIF and COUNTIF** functions to analyze sales, profit, revenue, and records across different regions.

## 🧩 Operations Performed

**01 — SUMIF for Sales Analysis**
Used the **SUMIF function** to calculate total sales for each region based on specified criteria.

**02 — Regional Profit Analysis**
Applied SUMIF to calculate the **total profit** generated across different regions.

**03 — Regional Revenue Analysis**
Used conditional calculations to determine the **total revenue** for each region.

**04 — COUNTIF for Record Analysis**
Applied the **COUNTIF function** to count the number of records associated with each region.

**05 — Conditional Data Analysis**
Used criteria-based Excel functions to summarize and analyze the DMart sales data according to region.
